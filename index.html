02 · UBUNTU

Preparar el VPS casero

1

Actualizar Ubuntu

sudo apt update
sudo apt upgrade -y
2

Comprobar Docker

docker --version
docker compose version
3

Comprobar Swarm

sudo docker service ls

No ejecutes docker swarm init si tu nodo ya pertenece a un Swarm.

4

Entrar a Dokploy

http://192.168.100.3:3000

La IP es un ejemplo para una red local. Usa la IP real de tu servidor.

03 · GITHUB

Crear el repositorio

GitHub · New repository
Repository name
ubuntu-dokploy-web
Description
Mi página publicada con Ubuntu y Dokploy
PublicPrivate

Pasos visuales

  1. En GitHub pulsa + → New repository.
  2. Escribe el nombre del repositorio.
  3. Elige la visibilidad.
  4. Crea el repositorio.

GitHub documenta la creación de repositorios desde la interfaz web. Después puedes subir tu proyecto mediante Git.

05 · DOKPLOY

Vincular GitHub con Dokploy

01

Git → GitHub

Entra a la sección Git de Dokploy y selecciona GitHub.

02

Create Github App

Crea una aplicación con un nombre único, por ejemplo Dokploy-Github-App.

03

Install

Instala la aplicación en tu cuenta de GitHub.

04

Seleccionar repositorio

Puedes permitir todos los repositorios o solamente el que vas a desplegar.

05

Install & Authorize

Autoriza el acceso y vuelve a Dokploy.
